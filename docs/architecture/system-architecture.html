The Big Idea: What is ShowMe?

ShowMe is a smart product-understanding assistant that answers user questions using the simplest, most effective format: Text, Image, or Video.

1 The Modality Hierarchy

  • 📝 Text First: If basic and direct (weights, rules, specs), answer in concise text.
  • 🖼️ Image Next: If locating a part or visual appearance, show a photo with callouts.
  • 🎥 Video When Needed: If seeing motion, direction, or sequence is required, show a video demonstration.

2 Retrieval-First, Then Generation

  • 🔍 1. Retrieve First: For any format, check if approved text facts, photos, or videos already exist.
  • 🕵️ 2. Verify Completeness: Check if retrieved content completely answers the question.
  • 🎥 3. Generate if Missing (async): Queue photo callouts or purpose-built videos when existing media is missing or incomplete — the user gets a verified fallback immediately; the generated asset is verified (and corrected if wrong) offline, then published to the Asset Library and announced.
🛡️

The ShowMe Rule

Always pick the least complex format that answers the question completely. Always retrieve verified content first; generate asynchronously when missing — nothing generated is served before it passes verification. Where this guide and low-level-design.md differ, the LLD governs.

Rich Use Cases Across All 3 Formats

📝

Format 1: Text Answers (Simple, Direct, Instant)

Product Specs & Limits

"How much does it weigh?" → 13.8 lbs (6.2 kg).

"Max child weight?" → 50 lbs (22.7 kg).

Rules & Policies

"Is fabric washable?" → Yes, gentle cold; air dry.

"Warranty period?" → 1-year limited.

Compatibility Facts

"Has headphone jack?" → Yes, 3.5mm left edge.

"Car seat fit?" → SnugRide without adapter.

🖼️

Format 2: Image & Photo Callouts (Location & Visual Appearance)

Finding Hidden Controls

"Where is the serial number?" → Highlights underside of rear axle on real photo.

"Where is the reset button?" → Highlights air purifier top bezel icon.

Visual State Checking

"What does it look like folded?" → Displays verified folded product photo.

"Mineral Green vs Black?" → Side-by-side color comparison.

🎥

Format 3: Video Demonstrations (Motion, Action & Procedures)

Folding & Unfolding in Motion

"Show me how to fold this stroller." → Video checks for thumb-latch release $\to$ handle squeeze $\to$ collapse $\to$ auto-lock click.

Assembly & Accessory Snapping

"How to attach car seat adapter?" → Shows rail alignment and locking click.

Adjustments & Everyday Use

"How to recline the seat back?" → Demonstrates rear strap release clamp.

Disassembly & Washing

"How to remove fabric for wash?" → Shows snaps, loops, and anchors release sequence.

The 3 Asset Lanes

Lane Modality When to Use Production Method
Lane 1: Text & Facts 📝 Text Specs, weights, dimensions, warranty, rules. Retrieved directly from verified Evidence Graph.
Lane 2: Photo Callouts 🖼️ Image Locating parts, buttons, ports, serial numbers. Retrieved photo + automated 2D bounding-box callouts.
Lane 3: Video Demonstration 🎥 Video Motion, mechanisms, folding, assembly, cleaning. 1. Verified existing clip.
2. Purpose-built clip generated asynchronously if missing/incomplete — verified & corrected before publication; illustrated steps served immediately. Ungrounded "plausible" motion is never served as instruction.

These three user-facing lanes map to the LLD's internal factory lanes (LLD §7.4): Lane 1 is served directly from published claims; Lane 2 is produced by factory Lanes A (exact static visual) and B (purpose-built visual), with animated step cards produced by Lane C; Lane 3 is produced by factory Lanes D (procedural video) and E (labeled non-instructional transition).

7

Safety Traffic Lights (Consequence Tiers)

Tier C0

Informational

Colors, weights, dimensions. Automated validation.

Tier C1

Reversible Task

Everyday folding, reclining canopy, cup holder install. Automated check; instructional media still needs human sign-off in P0.

Tier C2

Purchase & Care

Fabric washing, wheel removal, third-party fit. Mandatory Human Sign-off.

Tier C3

Safety Critical

Car seat locks, harness strap re-threading. Mandatory sign-off + non-removable warnings.

P0 note: any instructional media — including C1 procedures — requires human sign-off before publication (LLD §7.5). "Sample audit" applies only to non-instructional C1 content.

5-Phase Implementation Roadmap (Milestone-Driven)

Phase 0 Deliverable: Test Suite & Rules

The Rulebook & Blueprints

Set the ground rules before writing complex code. Define how the system decides between Text, Picture, or Video, and write the safety checklist every answer must pass.

🎯 Working Demo: Automated test script proving the system accurately routes 50 sample questions into Text, Image, or Video.
Phase 1 Deliverable: Text Bot + Review UI

Read Manuals & Answer Text Facts (1 Pilot Product)

Teach the system to read 1 test product (e.g. Graco stroller) and answer factual questions. Build an easy review screen for humans to approve facts against highlighted manual sentences.

🎯 Working Demo: Ask "How much does this stroller weigh?" or "Is fabric washable?" → Get an instant 100% cited text answer.
Phase 2 Deliverable: Visual Callout & Step Card Generator

Highlighted Photos & Animated Diagrams

Answer "Where is..." and "How do I assemble..." questions visually by auto-drawing boxes/arrows on real photos and turning manual drawings into animated step cards.

🎯 Working Demo: Ask "Where is the serial number?" → Shows real photo with red circle. Ask "How to attach cup holder?" → Shows animated 3-step card sequence.
Phase 3 Deliverable: Video Retrieval & Generation Engine

Purpose-Built Video Demonstrations

Build the full video pipeline for mechanisms: search official video clips → verify if they completely show the action → generate a purpose-built demonstration clip asynchronously if missing or incomplete, verified and corrected before publication.

🎯 Working Demo: Ask "Show me how to fold this stroller with one hand" → Plays exact 5-second video clip showing thumb-switch slide, handle squeeze, and frame collapse.
Phase 4 Deliverable: Multi-Category 10+ Product Launch

Scale to 10+ Products

Expand from 1 pilot product to a full catalog across baby gear and electronics (strollers, car seats, laptops, appliances) with fast onboarding tooling.

🎯 Working Demo: A live, multi-product assistant answering questions across 10+ products using Text, Photos, and Videos.
