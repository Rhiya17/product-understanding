## Identity
- Brand: Levoit (by VeSync)
- Model (as stated in official spec table): **Core 300S**
- Levoit item SKUs: HEAPAPLVSUS0073 (original Core 300S manual/item code), HEAPAPLVSUS0073A (current Core 300S-P variant)
- Category: Smart True HEPA air purifier, cylindrical tower, top air outlet, 360° bottom-half air intake

## Physical
- Dimensions: 8.7 x 8.7 x 14.2 in / 22 x 22 x 36 cm
- Weight: 5.95 lb / 2.7 kg
- Form: rigid cylinder; grey top fan grille with central touch panel; perforated 360° intake shroud on lower half; filter loads from the bottom (flip unit, twist bottom cover counterclockwise)

## Performance
- CADR: 141 CFM / 240 m³/h
- Ideal room size (coverage): 1,051 ft² at 1 air change per hour; 219 ft² at 4.8 ACH
- Noise level: 22–50 dB (QuietKEAP technology; Sleep Mode marketed at ~22–24 dB)
- Rated voltage: AC 120 V, 60 Hz
- Rated power: 23 W
- Operating conditions: 14°–104°F / -10°–40°C

## Filtration
- 3-stage filter cartridge (single cylindrical unit): ultra-fine nylon pre-filter + True HEPA main filter + high-efficiency activated carbon filter
- Replacement filter: **Levoit Core 300 Series Original Filter, part "Core 300-RF"** (Levoit SKU HEACAFLVNUS0012A; 2-pack SKU HEACAFLVNUS0047A)
  - Compatible models per VeSync store: Core 300, Core 300-P, Core 300S, Core 300S-P, Core P350, Core P350-P
  - Specialty variants: 3-Stage Toxin Absorber, 3-Stage Pet Allergy, 4-Stage Smoke Remover
  - Filter lifespan: 6–8 months; filter life tracked in the VeSync app
- Filter replacement is a bottom-access procedure: power off/unplug, flip unit, twist filter cover counterclockwise, swap cartridge (handle tabs facing up), refit cover, then hold the filter reset control 3 s

## Smart features
- WiFi (2.4 GHz) + VeSync app: remote control, schedules, timers, filter life %, PM2.5 history, Auto/Sleep modes
- Voice control: Amazon Alexa and Google Assistant
- AirSight Plus laser PM2.5 sensor; air-quality ring indicator (blue = very good, green = good, orange = moderate, red = bad) drives Auto Mode fan speed

## Control panel (top touch panel, center of fan grille)
- Power (center), with WiFi status icon above and red "check filter" icon below
- Fan speed button with level indicators I / II / III
- Auto Mode button (A in circular arrow)
- Sleep Mode button — **secondary function: FILTER RESET; label under the moon icon reads "RESET FILTER (3S)" — press and hold 3 seconds after installing a new filter to clear the red filter indicator**
- Timer button (displays hours on the 2-digit "88H" display)
- Display light on/off button (sun icon)
- Display Lock button (padlock; child lock)
- Dotted blue air-quality indicator ring around the power button
